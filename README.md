# DCAPP (디캡)

디시인사이드 모바일 웹(m.dcinside.com)을 더 편하게 보기 위해 만든 **개인용 iOS 앱**입니다.
SwiftUI + WKWebView 기반의 사이트입니다. 웹브라우저 모바일 버전 기반으로 굴러갑니다.

> ⚠️ 디시인사이드와 관계없는 **비공식** 앱입니다. 개인 사용 목적으로 만들었으며, 사이트 구조가 바뀌면 일부 기능이 동작하지 않을 수 있습니다.

📸 스크린샷으로 보는 기능 소개는 [FEATURES.md](FEATURES.md)에 있습니다.

## 주요 기능

### 탐색
- **하단 바**: 홈 · 갤러리 · 개념글⇄전체글 · 검색 · 글쓰기
- **갤러리 모음**: 즐겨찾기, 방문 기록, 갤러리 찾기
- **갤러리 내 검색**: 말머리 · 검색 범위(제목+내용/제목/내용/글쓴이/댓글) · 개념글만 · 최근 검색어
- **홈 화면 정리**: 디시 첫 화면 대신 실북갤 순위만 보기
- **사이트 상단 메뉴 숨기기**: 앱 상단바와 겹치는 사이트 헤더·글쓰기 버튼 숨김
- **스와이프 뒤로가기**: 화면을 오른쪽으로 쓸어 뒤로가기 (민감도 조절), 갤러리 목록에서 쓸면 갤러리 창 열기

### 읽기
- **사진 보기**: 글 속 사진을 탭하면 전체 화면 — 핀치·더블탭 확대, 좌우로 넘기기, 위아래로 쓸어 닫기, 원본 저장(움짤 포함)
- **댓글**: 입력창을 키보드 바로 위에 고정, 댓글만 새로고침
- **글 보관함**: 글을 폴더별로 보관 (저장 당시 내용 함께 보관)
- **캡처**: 보이는 화면 / 전체 페이지 캡처

### 차단 · 정리
- **유저 차단**: 아이디 · IP · 닉네임 (글이나 댓글을 길게 누르거나 탭해서 선택, 직접 입력)
- **키워드 차단**, **디시콘 차단**
- **요소 숨기기**: 화면에서 원하는 부분을 탭해서 숨김
- 차단된 글은 **접기**(탭해서 보기) 또는 **완전히 숨기기** 선택

### 글쓰기
- 상단바에 **등록 · 임시저장 · 불러오기 · 계정** 버튼
- **자동 임시저장** 및 임시저장 글 이어 쓰기
- **자짤**: 미리 등록한 사진을 글쓰기 화면에 자동 첨부 (갤러리별 설정)

### 계정
- **여러 계정 저장**(키체인 암호화) 및 탭 한 번으로 계정 전환, 자동 로그인
- 로그인 후 뜨는 **비밀번호 변경 안내 자동 건너뛰기**

### 화면 · 편의
- **한손 모드**: 화면 위쪽을 비우고 아래쪽에서만 사용 (갤러리 이름 길게 누르기 / 핸들을 맨 위로 끌어 해제)
- **오른쪽 세로 버튼 막대** 표시 여부 선택 (끄면 ⋮ 메뉴가 상단바로 이동)
- **iPhone 듀오 대응**: 펼친 화면을 끝까지 사용
- **앱 아이콘 변경**
- **설정 백업 · 복원** (JSON, 비밀번호 제외)
- **FaceID/TouchID를 이용한 앱 잠금기능**
- **알림 기능** (실험적)

### 업데이트 · 바로 설치
- 앱을 열 때 **GitHub 최신 릴리즈 자동 확인** (설정 → 버전 정보 → 업데이트에서 끄기 / 직접 확인)
- **바로 설치**: 최신 릴리즈의 ipa를 **Feather · SideStore · LiveContainer** 중 고른 앱으로 바로 열어 설치
  - 설정 → 버전 정보 → 업데이트에서 "바로 설치에 쓸 앱"을 고른 뒤 "○○로 바로 설치"
  - 새 버전 알림창에도 "○○로 바로 설치" 버튼이 함께 나옴
  - 고른 앱이 기기에 설치돼 있어야 합니다
