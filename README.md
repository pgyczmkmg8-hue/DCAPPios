# DCAPP (디캡)

디시인사이드 모바일 웹(m.dcinside.com)을 아이폰 · 아이패드 · 아이폰 듀오에서 더 편하게 보기 위해 만든 **개인용 iOS 앱**입니다.  
SwiftUI + WKWebView 기반으로 동작합니다.

> ⚠️ 디시인사이드와 관계없는 **비공식** 앱입니다. 개인 사용 목적으로 만들었으며, 사이트 구조가 바뀌면 일부 기능이 동작하지 않을 수 있습니다.

📸 스크린샷으로 보는 기능 소개는 [FEATURES.md](FEATURES.md)에 있습니다. 스크린샷 속 갤러리는 앱 설명용 사진을 찍기 위해 제작자가 임의로 고른 곳이며, 제작자가 평소 활동하는 갤러리가 아닙니다.

## 주요 기능

### 홈 화면
- **갤러리 순위 홈**: **실북갤 · 흥한갤**을 바꿔 가며 **갤러리 · 마이너갤 · 미니갤 · 인물갤** 네 칸을 한 화면에서 보기, 칸마다 좌우로 밀어 **50위까지** 확인 (세부 설정 `홈 화면 대신 실북갤 순위 보기`)
- **분할 화면 홈**: 가로로 넓은 화면에서는 홈을 창 전체 폭으로 펼쳐 네 칸을 **2×2**로 배치

### 탐색 · 글 목록
- **컨트롤바**: 계정 · 메뉴 · 개념글⇄전체글(글 안 가로 바에서는 **댓글작성**) · 검색 · 글쓰기
  - 설정에서 **하단 가로 막대 ↔ 오른쪽 세로 막대**를 세로/가로 방향별로 따로 선택
  - 막대를 옆으로 밀면 둘째 칸(**나무위키 · 차단·메모 · 보관함/즐겨찾기 · 링크 공유**) 표시
  - 버튼 순서 · 접기 · 스크롤 시 자동 숨김 지원
- **상단 고정 말머리 · 필터**: 상단에 말머리 줄(필터 + `전체` 고정)이 고정되며, 깔때기 버튼으로 **특정 말머리 · 읽은 글 · 추천/댓글/조회수** 필터 적용
- **자동 이어 붙이기 & `N페이지` 구분선**: 목록 맨 아래로 스크롤하면 다음 페이지가 자동으로 이어지며, 상단에 지나온 페이지 번호가 표시됨
- **글 목록 롱프레스**: 글을 꾹 누르면 차단 · 메모 · 갤로그 · 작성글 찾기 메뉴 바로 열기
- **갤러리 정보 · 관리 내역**: ⋮ 메뉴에서 바로 열고, 앱 카드 모양과 다크모드로 보기
- **갤로그**: 갤로그 화면을 앱 스타일로 정리

### 검색 · 나무위키
- **갤러리 내 2탭 검색**: `갤러리 내 글 검색`(말머리 · 범위 · 개념글만)과 `통합검색`을 키보드 유지한 채 전환
- **실시간 갤러리 찾기**: 타이핑 중에도 정식 · 마이너 · 미니 · 인물 갤러리 실시간 검색 결과 표시
- **식별코드 · IP로 작성글 찾기**: 검색 시트 또는 닉네임/글 꾹 누르기 메뉴에서 해당 작성자의 글 모아서 보기 (유동은 IP 앞 두 칸 기준, 창을 닫아도 백그라운드 수집)
- **나무위키 검색**: 컨트롤바 둘째 칸 **나무위키**에서 **실시간 검색어** · **연관 검색어**를 보고, 실시간 검색어를 **왼쪽으로 밀어** 실검 사유를 텍스트로 확인하며 앱 내 창에서 바로 열람

### 읽기 · 댓글
- **추천 · 비추 칸**: 개추 · 비추를 한 줄에 모으고 실베추 · 펌 · 수정/삭제 정리, 추천 재시도 및 비로그인 코드 입력 지원
- **댓글**: 등록순 · 최신순 · 답글순 정렬, 세로 컨트롤바 사용 시 댓글 입력창 화면 하단 고정, 보안 확인 자동 대응
- **사진 보기**: 핀치 · 더블탭 확대, 좌우 넘기기, 원본 저장(움짤 포함) 및 전체 일괄저장, 본문 이미지 차단
- **본문 이미지 숨기기**: 켜면 본문 사진 · 움짤을 눌렀을 때만 불러오기 (데이터 절약)
- **투표**: 투표 상자를 앱 카드 모양으로 보여 주고, 보기 사진을 누르면 **원본 크기**로 확대해 보기
- **이미지 댓글 · 스포일러 · 디시콘 정보 창**: 앱 스타일로 정리하고 다크모드 대응
- **글 보관함 & 캡처**: 폴더별 오프라인 글 보관, 보이는 화면 / 전체 페이지 캡처

### 글쓰기
- **앱 글쓰기**: 등록 · 임시저장 · 불러오기 · 계정, 사진 포함 자동 임시저장, 갤러리별 자짤 자동 첨부, **금지어 등록 실패 시 첫 금지어 위치 자동 선택**
- **퀵 글쓰기**: 글쓰기 버튼을 **두 번 누르거나 길게 눌러** 첫 줄은 제목, 줄을 바꾸면 본문으로 바로 등록 (제목만 써도 등록)
- **투표 · 시리즈 만들기**: 디시 창 대신 앱 화면에서 작성
- **유튜브 링크**: 본문에 붙여 넣은 링크를 영상 칸으로 첨부

### 차단 · 메모
- **작성자 차단 · 메모**: 아이디 · IP · 닉네임별 차단 및 주황색 메모, **자동메모**(로그인 계정 아이디 자동 표시)
- **키워드 · 고급 차단**: 작성자 + 단어 복합 조건, 특수문자 · 공백 끼워넣기 우회 막기 지원
- **디시콘 · 이미지 차단 & 요소 숨기기**: 디시콘을 길게 눌러 **하나만** 또는 **패키지 전체** 차단, 본문 이미지 차단, 화면 요소 직접 탭해 숨김 (접기/완전 숨김 선택)

### 꾸미기 · 편의
- **글꼴 · 테마**: `.ttf` · `.otf` 글꼴을 가져와 앱과 웹 화면에 적용, 테마 프리셋 또는 **6자리 16진 색상**을 직접 지정
- **배경 음악 유지**: 영상을 틀어도 듣고 있던 음악이 멈추지 않음 (세부 설정)
- **접속 제한(429) 대응**: 요청이 몰려 접속이 제한되면 안내 화면을 띄우고 자동으로 다시 불러오기
- **계정 전환 화면 가림**: 저장한 계정으로 로그인하는 동안 원본 로그인 화면 대신 `로그인 중…` 표시

### 기기 · 계정 · 보안 · 업데이트
- **분할 화면 & 아이폰 듀오 대응**: 가로 넓은 화면에서 왼쪽 목록 · 오른쪽 글 나란히 보기, 접기/회전 시 보던 글 그대로 이어 보기, 듀오 세로/가로 바 안전 영역 대응
- **한손 모드**: 갤러리 이름을 0.5초 길게 눌러 켜고, 위쪽 핸들을 맨 위로 끌어 해제
- **계정 · 잠금 · 다중 프로필**: 다중 계정 키체인 저장 및 원탭 전환, Face ID / Touch ID + 기기 암호 잠금, 가림막 꾸미기, 프로필별 완전 분리, 설정 JSON 백업/복원
- **알림**: 새 댓글 앱 내 배너 및 알림 탭
- **업데이트 · 소스 배포**: GitHub / GitLab 릴리즈 자동 확인 및 Feather · SideStore · LiveContainer 바로 설치 (`source.json` 지원)
